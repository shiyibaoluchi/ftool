# ftool - 文件后缀处理工具

一个跨平台的桌面应用程序，用于对文件执行"添加.后缀 → 移除.后缀"操作。
页面有一个输入框，用于输入后缀，默认值为.xml
## 功能

- 📁 支持处理单个文件或整个文件夹
- 🔄 递归处理子文件夹中的所有文件
- 🖥️ 简洁美观的图形界面
- 📦 跨平台支持 (Windows, macOS)

## 技术栈

- **前端**: React + TypeScript + Vite
- **后端**: Rust + Tauri
- **打包**: Tauri (生成原生桌面应用)

## 安装依赖

```bash
# 安装 Node.js 依赖
npm install

# 安装 Rust (如果没有)
# Windows: https://rustup.rs
# macOS: brew install rust
```

## 开发

```bash
# 运行开发服务器
npm run tauri dev
```

## 构建

```bash
# 构建生产版本
npm run tauri build
```

构建完成后，生成的可执行文件位于:
- Windows: `src-tauri/target/release/ftool.exe`
- macOS: `src-tauri/target/release/ftool.app`

## 使用方法

1. 启动应用程序，确保应用界面完全加载并显示所有功能按钮。
2. 选择文件或文件夹进行处理，可通过以下三种方式：
   - 点击界面上的"选择文件"按钮，在弹出的文件选择对话框中选择单个或多个文件
   - 点击界面上的"选择文件夹"按钮，在弹出的文件夹选择对话框中选择目标文件夹
   - 直接将文件或文件夹从文件资源管理器拖入应用程序窗口的指定拖放区域
3. 确认选择的文件/文件夹列表无误后，点击"开始处理"按钮启动处理流程。
4. 处理完成后，在主界面查看处理结果，包括成功处理的文件数量、失败的文件数量及相关信息。
5. 应用程序将自动打开独立的控制台窗口，实时展示处理过程的详细日志信息，包括时间戳、处理的文件路径、操作状态及任何错误信息，以便于监控处理进度和排查问题。

## 工作原理

应用程序采用以下机制处理文件和文件夹：


对于单个文件处理流程：
1. 将目标文件重命名为"原文件名.后缀"格式
2. 完成第一步后，立即将文件重命名回原始文件名

对于文件夹处理流程：
1. 递归遍历所选文件夹及其所有子文件夹
2. 对遍历到的每个文件，依次执行上述单个文件的重命名操作序列

此处理过程相当于对文件系统执行了"触摸"操作，通过修改文件名再恢复的方式，触发文件系统对文件元数据（包括修改时间等属性）的更新，适用于需要刷新文件元数据的特定应用场景。
